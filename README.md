# EDS 223 Homework Assignment #2: Mapping and Visualizing Disadvantaged Communities in Los Angeles County

### Purpose: 

This repo houses code and visualizations for analyses performed on HOLC, EJScreen, and LA County crash data. 

### Repository Structure: 

```
EDS223-HW2
├── data
│   ├── ejscreen
│   ├── mapping-inequality
│   └── SWITRS_LA
├── HW2.qmd
└── README.md
```
### Data Access:
Environmental justice data accessed through the restructured EJScreen tool as the former website no longer exists: [EJScreen Website.](https://www.epa.gov/ejscreen) Google drive link for ease of access to the EJScreen dataset: [EJScreen Dataset](https://drive.google.com/file/d/1nG6Nj1bXfzQFOVMO8Km3eNy4SWu1YcIQ/view?usp=sharing)

Mapping and inequality data accessed through the Inequality tool hosted on the Mapping Inequality website. [Mapping Inequality](https://dsl.richmond.edu/panorama/redlining/data)

Bike and pedestrian data accessed through the Transportation Injury Mapping System hosted through UC Berkley. [Transportation Injury Mapping System](https://tims.berkeley.edu/)
